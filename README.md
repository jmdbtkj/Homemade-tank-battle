# 坦克大战 | Neon Tank

一个基于原生 HTML、CSS 和 JavaScript 的赛博朋克风格坦克大战游戏。

## 中文说明

### 功能

- 单人和双人本地合作模式
- 三个作战区域与多种难度
- 地图编辑器：绘制砖墙、钢墙、水域、丛林、基地和出生点
- 自定义玩家与敌方坦克图像
- 自定义地图背景图片
- 选择本地 BGM，并保存到自定义地图
- Web Audio 音效、暂停、关卡选择和本地进度保存

### 运行

无需构建工具。直接用现代浏览器打开 `index.html` 即可运行。

建议使用 Chrome、Edge 或 Firefox。浏览器首次播放声音时，点击页面或开始游戏即可授权音频。

### 数据说明

自定义地图、图像、背景、BGM 和进度保存在浏览器 `localStorage` 中，不会上传到服务器。

## English

### Features

- Solo and two-player local co-op modes
- Three sectors with multiple difficulty levels
- Map editor for bricks, steel, water, jungle, base, and spawn points
- Custom player and enemy tank images
- Custom local map background images
- Local BGM selection saved with the custom map
- Web Audio effects, pause, sector selection, and local progress persistence

### Run

No build tools are required. Open `index.html` in a modern browser.

Chrome, Edge, or Firefox is recommended. If audio is blocked initially, click the page or start a game to allow playback.

### Data

Custom maps, images, backgrounds, BGM, and progress are stored in the browser's `localStorage`; no server upload is involved.
