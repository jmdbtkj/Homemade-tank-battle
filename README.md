# 坦克大战

一个基于原生 HTML、CSS 和 JavaScript 的坦克大战游戏。

## 中文说明

### 功能

- 单人和双人本地合作模式
- 双人在线合作模式
- 三个作战区域与多种难度
- 地图编辑器：
  1.绘制砖墙、钢墙、水域、丛林、基地和出生点
  
  2.自定义玩家与敌方坦克图像
  
  3.自定义地图背景图片
  
  4.选择本地 BGM，并保存到自定义地图
  
  5.Web Audio 音效、暂停、关卡选择和本地进度保存

### 运行

无需构建工具。直接用现代浏览器打开 `index.html` 即可运行。

建议使用 Chrome、Edge 或 Firefox。浏览器首次播放声音时，点击页面或开始游戏即可授权音频。

### 数据说明

自定义地图、图像、背景、BGM 和进度保存在浏览器 `localStorage` 中，不会上传到服务器。

## English

# A Tank Battle Game

## Features

- Single-player and two-player local co-op modes
- Two-player online co-op mode
- Three combat zones with multiple difficulty levels
- Map editor:
  1. Draw brick walls, steel walls, water, forests, bases, and spawn points.
  2. Customize player and enemy tank images.
  3. Customize map background images.
  4. Select local BGM files and save them with custom maps.
  5. Web Audio sound effects, pause functionality, level selection, and local progress saving

## How to Run

No build tools required. Simply open `index.html` in a modern web browser to play.

Chrome, Edge, or Firefox is recommended. On the first launch, click the page or start the game to authorize audio playback.

## Data Storage and Privacy

Custom maps, images, backgrounds, BGM files, and game progress are stored in the browser's `localStorage` and are never uploaded to a server.
